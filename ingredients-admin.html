🍸 MyBar Ingredient Publisher

This tool prepares the shared ingredient file for GitHub. It does not edit GitHub automatically. Everyone can see the approved ingredients, but each person's inventory stays private.

1. Load your current ingredient database

Download community-ingredients.json from your GitHub repository before every update, then choose it below.

No file loaded yet. Load your current file before publishing changes.

2. Add an ingredient

Check ingredients in an approved cocktail

Paste ingredients from a recipe (one per line), or choose the latest community-recipes.json. Unknown ingredients are listed below and can be added to the shared database.

3. Review and publish

Upload the downloaded file to GitHub by editing the existing community-ingredients.json, pasting in the downloaded file contents, and committing. No changes appear on the public website until you do this.
